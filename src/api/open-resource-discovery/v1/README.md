This folder contains the ORD Provider implementation of an ORD Document API.

The example Product uses `foo:product:ord-reference-app:` and publishes its placeholder Vendor as `foo:vendor:Example:`. Replace `foo` and the Vendor identity with your own registered vendor namespace when adapting the example. Product and Vendor IDs use a vendor namespace and keep their version fragment empty; system-owned resource IDs use a system namespace.
